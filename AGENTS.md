# Project rules

- Keep official letter preview, printing, and Word export in the shared ReportLetter component so department and college letters use the same stationery.
- Import uploaded letter stationery through Lovable Assets pointers; personalize the heading email once with a canvas and reuse that image in preview, print, and Word headers to keep every format consistent.
- Resolve live staff college labels from the department's related college when reading staff; this avoids stale denormalized labels without altering report snapshots.
